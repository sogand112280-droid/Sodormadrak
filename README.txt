قالب سایت شماره ۲ - سفید و فیروزه‌ای
برای انتشار در GitHub Pages:
1) فایل ZIP را استخراج کنید.
2) فایل‌های index.html، style.css و script.js را در ریشه مخزن GitHub بارگذاری کنید (نه داخل پوشه جداگانه).
3) در Settings > Pages، گزینه Deploy from a branch را انتخاب کنید؛ Branch: main و Folder: /(root) و Save.
4) پس از انتشار، آدرس سایت به شکل https://USERNAME.github.io/REPOSITORY/ خواهد بود.

برای تغییر لینک تلگرام، عبارت https://t.me/LegalMadarek را در index.html جایگزین کنید.
این قالب خدمات صدور مدرک را ادعا نمی‌کند؛ صدور و تأیید مدارک رسمی در صلاحیت مراجع قانونی است.
